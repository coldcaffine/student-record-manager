# Student Record Manager (C)

A menu-driven console app in C to manage student records. Data is saved to a binary file, so records persist between runs.

## Features
- Add, display, search and delete student records
- Class average calculation
- Persistent storage using file handling

## Concepts used
- Structures and typedef
- Functions (call by value and call by reference)
- Arrays and pointers
- File handling (fopen, fread, fwrite, fclose)
- Loops, switch, and a menu-driven design

## Build and run
    gcc main.c -o student_manager
    ./student_manager
